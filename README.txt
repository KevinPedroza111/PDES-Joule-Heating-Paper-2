JOULE HEATING WEBSITE

Open "Joule Heating website.html" to begin.
Keep all files in this folder together. No internet connection is required.

Modules: components.html, procedure.html, schematic.html, measurements.html
3D model: 3D_Demo.html
Home-page image: apparatus.png
Printable circuit: use Print / save schematic as PDF in the schematic module.

The procedure has numbered step navigation and a Show all steps control.
The schematic has gate-high / gate-low controls and a sample-disconnection option.


Display controls: use Light mode / Dark mode in the header. Pause motion stops the decorative and heating-cycle animations. Preferences are remembered when browser storage is available.
Keep experience.css and experience.js with the HTML pages.
