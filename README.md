# PDES Joule Heating Experiment Guide

An interactive guide to electrothermal actuation of liquid-metal-coated PDES elastomers: the hardware, the step-by-step procedure, a live circuit, how to take the measurements, the collected test data and a 3D model of the apparatus.

**View the website:** https://kevinpedroza111.github.io/PDES-Joule-Heating-Paper-2/

## Open it on your own computer

The site runs entirely from these files, with no internet connection or server needed.

1. Download the repo (green **Code** button → **Download ZIP**, then extract it) or clone it.
2. Double-click **`index.html`**.

## Pages

| Page | What it covers |
|---|---|
| `Joule HeatingWebiste.html` | Home page and overview |
| `components.html` | What each instrument and part does |
| `procedure.html` | The experiment, step by step |
| `schematic.html` | Interactive circuit with a simulated oscilloscope |
| `measurements.html` | What to record and how strain is calculated |
| `data.html` | Interactive charts for every analyzed test |
| `3D_Demo.html` | Rotatable 3D model of the apparatus |

## Updating the data

The Data page reads `data.js`, which is generated by `exportWebsiteData.m` in the lab's MATLAB analysis repo. After analyzing new videos, run that script there, copy the new `data.js` into this repo and push. The website updates automatically within a minute or two.
